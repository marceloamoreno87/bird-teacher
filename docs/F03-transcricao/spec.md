# F03 · Transcrição ao vivo

Normalizar os dois fluxos para PCM mono a 16 kHz, reconhecer no idioma selecionado com whisper.cpp e ordenar pelo início da captura.

Depende de F02. O contrato cobre a integração pelo aplicativo desktop.

Configurações exibe idioma, tamanho e perfil dos modelos. Instalar verifica o arquivo e o disponibiliza para uso offline. Ativar aplica o modelo e o idioma selecionados. Ao reabrir, o idioma inicial é inglês. A seleção de modelo fica disponível entre sessões. As prévias usam uma decodificação rápida e a versão final considera a fala até uma pausa ou o limite do trecho.
