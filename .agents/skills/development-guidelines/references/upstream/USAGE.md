# Uso local: development-guidelines

Este recurso é distribuído com o scaffold. Consulte [SKILL.md](../../SKILL.md) para operações, parâmetros e procedimentos.

Execute a skill pelo identificador `$development-guidelines` no projeto. As referências deste diretório são locais e adaptadas para execução na sessão atual; não há instalação de marketplace ou plugin.

A origem histórica e a revisão de referência estão em `.codex/harness-sources.json`, na raiz do projeto.
